## User Stories

### STORY-001: 即時預覽功能

```
As a Neovim 用戶
I want to 在瀏覽器中即時預覽 D2 圖表
So that 我可以立即看到圖表的視覺效果
```

**Acceptance Criteria:**

- [ ] **AC-01**: 啟動預覽伺服器
  - 使用 d2 CLI 的 watch 模式
  - 自動開啟預設瀏覽器
  - 支援指定預覽埠號

- [ ] **AC-02**: 即時更新機制
  - 檔案儲存時自動更新預覽
  - 支援熱重載不需手動重整
  - 保持捲動位置和縮放狀態

- [ ] **AC-03**: 預覽控制指令
  - 提供 :D2Preview 啟動預覽
  - 提供 :D2PreviewStop 停止預覽
  - 顯示預覽狀態和 URL 資訊

---

### STORY-002: 導出圖片功能

```
As a Neovim 用戶
I want to 將 D2 圖表導出為圖片格式
So that 我可以在文件或簡報中使用這些圖表
```

**Acceptance Criteria:**

- [ ] **AC-01**: 支援多種導出格式
  - 支援 SVG 向量圖格式導出
  - 支援 PNG 點陣圖格式導出
  - 支援 PDF 文件格式導出

- [ ] **AC-02**: 導出指令介面
  - 提供 :D2Export 指令
  - 支援指定輸出路徑和檔名
  - 顯示導出成功訊息和檔案位置

- [ ] **AC-03**: 導出選項配置
  - 支援設定導出圖片解析度
  - 支援選擇不同的佈局引擎
  - 支援套用不同的視覺主題

---

### STORY-003: 語法高亮支援

```
As a Neovim 用戶
I want to 在編輯 D2 檔案時有語法高亮
So that 我可以更清楚地閱讀和編寫 D2 圖表定義
```

**Acceptance Criteria:**

- [ ] **AC-01**: 識別並高亮 D2 語法元素
  - 支援節點、連線、屬性等核心語法高亮
  - 支援註解和字串的不同顏色顯示
  - 支援巢狀結構的正確高亮

- [ ] **AC-02**: 整合 tree-sitter 語法解析
  - 使用 tree-sitter-d2 進行語法解析
  - 確保高亮效能流暢不卡頓
  - 支援大型 D2 檔案的即時高亮

- [ ] **AC-03**: 自動識別 D2 檔案類型
  - 自動識別 .d2 副檔名
  - 設定正確的 filetype 為 d2
  - 載入對應的語法高亮規則

---

### STORY-004: 錯誤提示與修正

```
As a Neovim 用戶
I want to 獲得詳細的錯誤提示和修正建議
So that 我可以快速解決 D2 語法問題
```

**Acceptance Criteria:**

- [ ] **AC-01**: 詳細錯誤資訊
  - 顯示錯誤的具體位置和行號
  - 提供錯誤類型分類說明
  - 顯示錯誤的上下文程式碼

- [ ] **AC-02**: 智慧修正建議
  - 提供常見錯誤的修正建議
  - 支援一鍵快速修正功能
  - 顯示修正前後的差異預覽

- [ ] **AC-03**: 錯誤管理介面
  - 整合到 Neovim 診斷系統
  - 支援錯誤嚴重程度分級
  - 提供錯誤統計和摘要資訊

---

### STORY-005: D2 CLI 整合

```
As a Neovim 用戶
I want to 在 Neovim 中直接使用 D2 CLI 功能
So that 我不需要切換到終端機執行 D2 指令
```

**Acceptance Criteria:**

- [ ] **AC-01**: CLI 指令包裝
  - 檢測 d2 CLI 是否已安裝
  - 包裝常用 d2 指令為 Vim 指令
  - 支援傳遞 CLI 參數選項

- [ ] **AC-02**: 輸出結果處理
  - 捕獲 CLI 指令輸出
  - 在 quickfix 視窗顯示錯誤
  - 顯示執行成功或失敗訊息

- [ ] **AC-03**: 非同步執行
  - 使用 Neovim job API 執行指令
  - 不阻塞編輯器操作
  - 提供執行進度指示

---

### STORY-010: 自動縮排功能

```
As a Neovim 用戶
I want to 在編寫 D2 檔案時有自動縮排
So that 我的程式碼格式保持一致且易讀
```

**Acceptance Criteria:**

- [ ] **AC-01**: 支援基本縮排規則
  - 在大括號內自動增加縮排層級
  - 關閉大括號時自動減少縮排
  - 保持同層級元素對齊

- [ ] **AC-02**: 智慧縮排處理
  - Enter 鍵後自動縮排到正確位置
  - 支援多層巢狀結構的縮排
  - 貼上程式碼時自動調整縮排

- [ ] **AC-03**: 縮排配置選項
  - 支援設定縮排寬度（預設 2 空格）
  - 支援空格或 Tab 縮排選擇
  - 與 Neovim 的縮排設定整合
